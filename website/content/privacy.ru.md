### Коротко

Это политика конфиденциальности сайта binateam.site. Сайт ничего не собирает: на нём нет регистрации, форм, рекламы, аналитики и счётчиков посещений. У каждого приложения Bina Team своя политика — для sBoard она опубликована на странице sBoard.

### Кто отвечает за сайт

Сайт ведёт команда Bina Team. Вопросы о данных: sboard.app@gmail.com.

### Что сайт хранит в вашем браузере

• Выбранный язык и тему оформления — в localStorage браузера, чтобы не спрашивать их снова. Эти настройки не покидают ваше устройство.
• Копии страниц сайта — в кэше Service Worker, чтобы сайт открывался без интернета. В кэше нет ваших данных, только файлы сайта.
• Сайт не использует cookie.

Удалить всё это можно в настройках браузера: «Очистить данные сайта» для binateam.site.

### Хостинг

Сайт размещён на GitHub Pages (GitHub, Inc.). Как и любой веб-сервер, GitHub может записывать технические сведения о запросах — например IP-адрес — для безопасности и работы сервиса. Мы не получаем эти журналы. Подробнее — в заявлении о конфиденциальности GitHub: docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

### Сторонние ресурсы

Сайт не загружает сторонние скрипты, шрифты и счётчики. По ссылкам он ведёт на GitHub (релизы, исходный код, GitHub Issues) и открывает почтовую программу для писем. На этих ресурсах действуют их собственные правила. Сообщения в GitHub Issues публичны — не пишите в них пароли, коды и другие личные данные.

### Письма

Если вы пишете нам на почту, мы получаем ваш адрес и текст письма и используем их только для ответа. Мы не передаём их третьим лицам.

### Дети

Сайт не предназначен специально для детей и не собирает данные о них.
